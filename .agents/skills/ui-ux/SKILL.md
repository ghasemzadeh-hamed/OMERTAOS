# OMERTAOS UI UX Skill

## Execution Mode

- For implementation requests, edit the existing Console components/styles and
  run focused unit/build or flow validation. Do not return a mock plan instead.
- For review-only requests, remain read-only and cite concrete UI evidence.
- Preserve the existing design system and Gateway boundary.

## Console Areas

- Dashboard, agents, tasks, logs, tools, models, and services
- System monitor, config center, Windows bridge, and workflow designer

## Rules

- Keep UI consistent, responsive, accessible, and clear.
- Do not bypass Gateway from the UI.
- Reduce unnecessary clicks and show useful empty/loading/error states.
- Avoid clutter and preserve RTL/Farsi behavior where relevant.
