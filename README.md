## Installation
Follow these steps to install OMERTAOS:
1. Download the latest version from the releases page.
2. Create a bootable USB or burn the ISO to a DVD.
3. Boot from the installation media.
4. Follow the on-screen instructions to complete the installation.

## Usage
After installation, you can start using OMERTAOS immediately. Explore the features and make the most of your experience.
